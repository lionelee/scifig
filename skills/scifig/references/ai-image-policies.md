# Publisher policies on AI-generated figures

Condensed from a table published under CC BY 4.0 (source and attribution:
https://github.com/lionelee/scifig/blob/main/NOTICE.md), **last verified 2026-07-21**. Policies change
often. Use this table to warn the user early, and give that date with every row you quote. If
you have web access, open the row's official page and confirm it before the user decides
anything on it; if you cannot, say that the row is unconfirmed since that date.

The table lists publishers, so find the journal's publisher first: Cell Reports is a Cell Press
journal, Nature Communications a Nature Portfolio journal.

| Publisher | AI-generated illustrations and schematics | Images of real data | Disclosure | Official page |
|---|---|---|---|---|
| Springer Nature / Nature Portfolio | Not permitted for publication; limited exceptions case by case | Non-generative ML enhancement may be used if disclosed in the caption | Caption (image tools); Methods (LLM text) | https://www.nature.com/nature-portfolio/editorial-policies/ai |
| Elsevier, incl. Cell Press | Explanatory images (flow charts, timelines, schematic conceptual illustrations, workflow diagrams) allowed with disclosure. **Graphical abstracts: general-purpose AI tools not permitted.** Cover art needs prior editor permission | Prohibited: AI must not create or alter images of primary data | Each image caption (tool, version, how used) and the article's AI declaration | https://www.elsevier.com/about/policies-and-standards/generative-ai-policies-for-journals |
| Wiley | Permitted for data visualizations and illustrations; restricted for photographs | Restricted | Disclose at submission | https://authors.wiley.com/ethics-guidelines/index.html |
| Taylor & Francis | Permitted for data visualizations, conceptual illustrations, flow diagrams, teaching illustrations | Prohibited for research, clinical and diagnostic image outputs | In the article: tool name and version, how and why used | https://taylorandfrancis.com/our-policies/ai-policy/ |
| IEEE | Allowed if disclosed | Not addressed | Acknowledgments: the AI system and the affected sections | https://open.ieee.org/author-guidelines-for-artificial-intelligence-ai-generated-text/ |
| ICMJE (cross-field) | Not prohibited; authors take full responsibility | Authors must assert no plagiarism in AI-produced images | Cover letter and the relevant section; Methods if used for figure generation | https://www.icmje.org/recommendations/browse/roles-and-responsibilities/defining-the-role-of-authors-and-contributors.html |
| JAMA Network | Clinical illustrations created or manipulated by AI not permitted; other AI content discouraged | Not permitted | Acknowledgment or Methods: content, tool name, version, manufacturer | https://jamanetwork.com/journals/jama/fullarticle/2807956 |
| PLOS | Not addressed as a category | Must not be manipulated in misleading ways; AI must not fabricate data | Methods or Acknowledgements: tools, how used, how validity was checked | https://journals.plos.org/plosone/s/ethical-publishing-practice |
| Science / AAAS | Reported as not permitted without editor permission (the source marks this row unverified) | Not confirmed | Reported: cover letter and Methods, including prompt, tool and version | https://www.science.org/content/page/science-journals-editorial-policies |

A publisher that is not listed has no entry here: say so and look up the journal's author
instructions.

## Additions

Read from Elsevier's policy page on 2026-11-11 (the page says "Policy updated June 2026"); not
part of the table's source. Quote these two points with that date:

- **Graphical abstracts.** Elsevier encourages dedicated scientific illustration tools instead,
  and its FAQ names BioRender and Mind the Graph as examples; the tool goes in the caption.
- **Charts and other data visualisations.** AI tools are permitted only when the visual is
  derived directly from the underlying data by reproducible methods reported in Methods, with
  the name of the tool, its version and its developer there.
